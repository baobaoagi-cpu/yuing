# MING 帳號基礎資料：本地實作與驗收邊界

2026-10-14，威廷提供 MING 的開帳背景。資料僅屬 `MING` 登入帳號：王跃明、男性、資深工程師、熟悉 AI 與後端、威廷的好友、協助準備陳端倪中國區伺服器，以及端倪的獨立陪伴使用者。來源標為 `account_setup_user_provided`，來源時間只到日期精度；資料錄入時間另存為 `recorded_at`，信心標為 `user_provided_unverified`。這些不是從聊天推斷、不是已獨立核實的履歷，也不授予伺服器或部署權限。

登入後 `GET /api/v2/profile` 回傳 `account_seed`。本人可用同源的 `PATCH /api/v2/profile/account-seed/<field>` 與 JSON `{"value":"新值"}` 更正，或用 `{"value":null}` 撤回。更正與撤回會新增修訂列，保留原來源；回傳最新狀態。資料位於 `POC_COMPANION_ROOT/memory.sqlite3`，與圖關係及知識資料庫分層。候選記憶仍需另行同意。

文字聊天只從登入 session 對應的資料層取值。通話只在 `POC_VOICE_CONTEXT_ENABLED=1`、簽名密鑰與持久儲存皆可用時，由伺服器把同帳號資料放入限時、綁房間的簽名封包；Agent 驗簽後使用。前端送入的 `owner_id`、資料或房名不選擇帳號。上下文要求自然陪伴、逐步了解，不預設只談技術；「陪伴」僅指本人主動使用時的對話，不觸發主動私訊、排程或對外聯絡。

本地單元測試涵蓋登入回讀、跨帳號拒絕、更正與來源保留、文字模型請求、通話簽發與驗簽。此紀錄不代表已部署，亦不代表王跃明已用真實手機通話或接受體驗。
